# Book PDFs go here (not committed to git)

Download NCERT chapter PDFs from ncert.nic.in and place them like this:

    data/books/class10/science/ch01.pdf
    data/books/class10/science/ch05.pdf
    data/books/class10/science/ch11.pdf

Then describe them in `data/books/manifest.yaml` (see the README, "Ingest the books").
